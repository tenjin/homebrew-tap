# Code of conduct

This repository follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in its issues, pull requests and discussions is expected to uphold it.

Report unacceptable behaviour to [support@tenjin.com](mailto:support@tenjin.com). Reports are reviewed promptly and kept confidential.
